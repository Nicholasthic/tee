# S&N Golf — brand files

Three families, each with a different job. Every file is vector, two inks, and
scales from a cap badge to a back print.

| family | job |
|---|---|
| **Scorecard** (`sn-*`) | The identity. Cap, ball marker, app icon — anything that has to be consistently you. |
| **Sunburnt** (`sunburnt-*`) | The loud graphic tee. Seasonal, print it once, retire it. |
| **Golf Made** (`golfmade-*`) | Heritage. Polo, leather bag tag, the cap for a proper course. |
| **Merch** (`merch-*`) | One-off garment designs. |

**Don't mix two families on one garment.**

Before anything goes to a printer, convert the type to outlines —
`Type > Create Outlines` in Illustrator, `Path > Object to Path` in Inkscape.
Otherwise their machine substitutes its own font.

# S&N Golf — Scorecard

**Beers · Bogeys · Bad Decisions**

The initials sit in scorecard boxes and the ampersand takes the birdie ring —
scrawled, overshooting, the way you draw it leaning on a cart. On the back
print the ring goes round the *score*, not the word, because that's what a
birdie actually looks like on a card.

| file | use |
|---|---|
| `sn-chest.svg` | Left chest, 75–90 mm wide |
| `sn-chest-reversed.svg` | Same, on dark cloth |
| `sn-back.svg` | Back print, 260–300 mm |
| `sn-back-reversed.svg` | Same, on dark cloth |
| `sn-small.svg` | Cap, sleeve — boxes and ring only |
| `sn-small-1colour.svg` | Single screen, and anything embroidered |

Pencil `#43484E` · Red `#CE3226` · Paper `#FBF7EC` · Graphite `#22262A`
· Olive `#5C6B3D`

Two screens: pencil for everything, red for the ring.

**Before printing** convert the type to outlines — `Type > Create Outlines`
(Illustrator) or `Path > Object to Path` (Inkscape). Otherwise the printer's
machine substitutes its own font and the letters stop fitting the boxes.

**Below ~40 mm** use the small cut. The tagline and micro-labels fill in, and
a digitiser will lose them regardless.


## Sunburnt — the graphic tee

A separate family to the scorecard mark, on purpose. Scorecard is the
identity (cap, ball marker, app icon); Sunburnt is a graphic — loud,
seasonal, printed once and then retired.

| file | use |
|---|---|
| `sunburnt.svg` | Primary, rust on bone |
| `sunburnt-reversed.svg` | On ink or olive |
| `sunburnt-back.svg` | Back print with Beers · Bogeys · Bad Decisions |
| `sunburnt-chest.svg` | Chest hit, one line, 90 mm |
| `sunburnt-1colour.svg` | Single screen |

Rust `#C4441F` · Clay `#E8783C` · Gold `#EFA43A` · Bone `#F3E8D5` · Ink `#241C18`

Everything leans 13° — bands and letters share one skew, so don't re-skew
parts separately. Keep the bands above 2 mm at print size or they close up
on press.

**Don't** put the birdie ring inside the Sunburnt lockup. Keeping the two
families apart is what makes each one work.


## Golf Made — the heritage line

"Golf made" is what a clubmaker stamped into a hickory shaft. So this family
is built as stamps rather than logos: pressed, serif, town and year always
present.

| file | use |
|---|---|
| `golfmade-stamp.svg` | The oval maker's stamp |
| `golfmade-band.svg` | Long thin band — hem, sleeve, inside a cap |
| `golfmade-roundel.svg` | Crossed hickories — cap badge, bag tag |

Ink `#2A2620` · Oxblood `#7B2D26` · Parchment `#EFE6D2` · Gold `#A8874E`
· Bottle `#1F3B2C`

Set in Georgia — the closest thing to a period face that every printer
already has. If you want it sharper later, Caslon or Clarendon is the
upgrade.

This family suits a distressed or halftone finish, unlike the other two.

## Which family goes where

- **Scorecard** — the identity. Cap, ball marker, app icon, anything that has
  to be consistently you.
- **Sunburnt** — the loud graphic tee. Seasonal, print it once.
- **Golf Made** — heritage. Polo, leather bag tag, the cap for a proper course.

Don't mix two families on one garment.
